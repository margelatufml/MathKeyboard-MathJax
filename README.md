# MathKeyboard — React Math Input Component

An interactive **math keyboard component** built with React that renders mathematical expressions using **MathJax**.

## Tech Stack

- **Framework:** React
- **Math Rendering:** MathJax
- **Language:** JavaScript

## Features

- Interactive on-screen math keyboard
- Real-time MathJax rendering of mathematical expressions
- Support for common mathematical symbols and operators
- Component-based React architecture

## Getting Started

```bash
cd mathkeyboard-react
npm install
npm start
```

## Use Case

Useful for educational platforms, online assessments, and any application requiring mathematical input without a physical keyboard.
